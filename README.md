# zomota_dataset_analysis

## Overview
This project analyzes the Zomato dataset to understand restaurant ratings, cuisines, pricing, and location preferences.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Objectives
- Clean and preprocess the dataset
- Analyze ratings, cuisines, and locations
- Create visualizations
- Generate insights and recommendations

## Files
- Zomato_Analysis.ipynb
- Zomato_Analysis.pdf

## Conclusion
The analysis identified important trends in restaurant ratings and customer preferences.
